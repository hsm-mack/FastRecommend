# FastRecommend

## Sistema Inteligente de Recomendação de Itens de Cardápio com Machine Learning

Projeto desenvolvido para a disciplina **Projeto Aplicado III** da Universidade Presbiteriana Mackenzie.

**Integrante:** Fatima Harumi de Souza Matsuoka  
**Ano:** 2026

## Objetivo geral

Desenvolver e avaliar um sistema inteligente de recomendação baseado em técnicas de Machine Learning capaz de sugerir receitas e itens alimentícios a usuários a partir de padrões identificados nas interações históricas e nas características dos itens.

## Base de dados

Será utilizada a base **Food.com Recipe & Review Data**, disponibilizada pelo grupo de pesquisa de Julian McAuley, da University of California San Diego (UCSD).

Fonte: https://cseweb.ucsd.edu/~jmcauley/datasets.html

## Pipeline inicial

Aquisição dos dados → Verificação da estrutura e qualidade → Análise exploratória → Limpeza e preparação → Construção das relações usuário-item → Desenvolvimento do modelo de recomendação → Geração das recomendações → Avaliação → Análise dos resultados.
